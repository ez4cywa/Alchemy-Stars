# 软件内的 RF 握持适配方案

本方案已接入软件的 RF 静态姿势、单动画、单文件动画库三个入口。生产代码不按 Hawk、Reload、Inspect 等文件名修正，也没有写死这些动画的帧号；每个工程用所选参考动画重新标定。Hawk 的五段动画只作为回归样例。

## 用户操作

在 RF 设置中选择 RF 手臂文件、源单位、参考动画与参考帧，建议使用正常持枪 Idle。开启“自动对齐主掌面”和“局部握持拟合（修改导出手型）”，选择所需输出模式，再生成 RF 结果。换武器或换手臂后重新生成，标定不会跨素材误用。

局部握持拟合默认关闭；工程保存该选择及参考动画，旧工程不自动修改手型。参考帧不靠近武器时，软件提示重新选择持枪姿势，仍可执行手型拟合，但不会把没有捕获接触的结果冒充武器贴合。

## 一条共享处理流程

参考帧标定 → 逐帧目标与离手状态 → 整手靠拢并重算手臂 → 受限局部拟合 → 烘焙和验收。

| 模块 | 职责与约束 |
| --- | --- |
| `RavenfieldAdaptationEngine` | 读取工程、生成完整源 CAST、统一坐标、隔离 Blender 运行、保护输入与原子发布结果。 |
| `ravenfield_shape.prepare_grip` | 只在参考帧捕获四掌面与三虎口的固定三角形重心锚点；在导出副本上标定形状、建立局部控制。静态和动画共用此入口。 |
| `SupportContacts` | 从参考姿势捕获左掌附近的武器材质点，保持接触锚稳定；依据源手离开程度平滑释放，不在每帧搜索一个新表面把手吸过去。 |
| `GripContactFitter.fit` | 根据虎口到接触目标的平均位移将整只左手靠向武器，并重算肘腕连接；再联合修正左右手七点残差。各控制独立限幅，手动微调最后生效。 |
| `ravenfield_animation` | 所有片段使用同一个标定模型，逐帧烘焙原骨与辅助骨，并检查实际蒙皮、片段边界和输出姿势。 |

模块把形状、接触、权重与求解细节封装在参考标定及逐帧拟合的接口后面。界面只保存用户意图，不计算顶点或维护另一套静态拟合算法。

## 当前默认标准

- 左右手每帧四掌面加三虎口，最大目标误差不超过 **5 mm**。不放宽异常片段的门槛。
- 参考姿势的左掌四点距武器均不超过 12 mm、虎口三点均不超过 35 mm 才捕获完整接触。七点目标均在参考三角形朝手侧的**内侧 1.5 mm**，允许手掌穿模；不再保留外侧间隙。
- 整手靠拢位移上限 40 mm，随接触权重平滑释放；原骨绑定与长度不改，肘腕位置重新求解，避免单独移动手腕产生断口。
- 相对参考接触间隙，源手再离开 6–24 mm 时平滑释放。这里不是将绝对距离 24 mm 内的任意手都吸住。
- 每个局部控制平移不超过 **30 mm**。一个控制触限不会缩小其他独立控制的修正。
- 原始素材、原骨绑定与骨长、武器几何和位姿不变；不增加任何顶点的有效蒙皮影响数量。导出副本的手部局部网格和辅助骨允许变化。

这些是当前 RF 适配器的默认标准，不是通用于所有骨架命名、任意手型和任意游戏导入设置的承诺。目标为当前支持的 COD 手部骨架与 RF 手臂骨架；不支持的输入应明确报错，不靠改采样点或放大容差伪造通过。

## 结果与失败处理

报告分别记录 `targetPointsM`（配置后的握持目标）、`authoredPointsM`（原动画加手动微调）和实际 `afterPointsM`。历史字段 `sourcePointsM` 保留为目标字段的兼容别名，不能再把它当成未经接触调整的原始手掌。

`localHandFit.contract` 记录版本和不变量；`leftSupportReference` 记录接触是否建立、原因、阈值与固定武器锚点。动画报告逐帧保留左右掌面/虎口误差、左掌接触权重、控制位移和最坏帧。没有捕获武器接触时明确提示，不静默吸附。

`palmContact.passed` 仅表示上述握持目标通过。超限时保留可检查的文件和报告，界面显示“握持贴合需检查”。几何、非有限数值、骨骼或输入保护失败则中止发布。不要把“生成文件”与“质量通过”混为一谈。

## 回归与维护

`test-ravenfield-adapter.py` 检查控制上限、旋转等变性、接缝、接触释放和无武器降级；`verify-ravenfield-grip-animation.py` 在真正蒙皮上检查失败姿态或全部源帧；`verify-ravenfield-palm.py` 检查参考帧、手动偏移与真实武器间隙；`verify-ravenfield-fbx.py --library --output <报告>` 独立重导全部时间线。

RF.6 的全部 563 个源帧通过，最大目标误差约 4.278 mm。Idle 掌面及虎口七点到武器的距离从最远 24.300 mm 降至不超过 1.453 mm（目标允许内穿），并增加整手靠拢以覆盖局部控制外的可见轮廓。`verify-ravenfield-palm.py --local-hand-fit --require-weapon-contact --require-pass` 可复现旧版失败与新版通过。完整记录见 [验证记录](ravenfield-adapter-validation.md)。

原 RF 模型本身最多七个有效权重，四权重导入器仍可能改变原手型；本方案不增加该数量。用户已允许手掌穿模，因此不再以全表面无穿透为目标。七点距离仍不能替代第一人称轮廓检查；Unity/RFTools 游戏内表现未验证。
