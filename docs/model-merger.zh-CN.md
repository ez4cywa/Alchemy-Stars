# 模型合并工作区

入口：左侧「模型合并」（Ctrl+7）。本模块将 ModelMergerGUI 的 CAST 工作流接入 Alchemy Stars，而不是启动另一个 GUI。

## 来源与边界

合并、填弹、手臂拼接和预览解析采用 `ez4cywa/ModelMergerGUI` 的 2.5.0 核心，固定提交 `7cc474e707b1e3d971bfe2cb4855ec8a7df34e1d`。原样来源代码及 MIT 许可位于 `third_party/modelmerger`。Alchemy Stars 的新增接口负责进程通信、桌面界面和任务调度。

不会将 RF 实验分支的改动混入此版本，也不修改 Unity 工程、骨骼约定或已有动画导出流程。输出仍为 CAST；需要 FBX 等格式时使用软件已有导出流程。

## 输出命名

输出名默认按武器代号推导（取文件名中部件类型段前一段）：合并输出 `<代号>.cast`（如 `att_sat_vm_ar_eagle_rec_LOD0` → `eagle.cast`），弹匣装填 `<代号>_filled.cast`，手臂拼接 `<代号>_viewhands.cast`；找不到部件类型段时回退完整文件名，名称始终可手动修改。

输出文件夹已存在相同代号文件时，本模块自动做区分，不会静默覆盖：先提取本次输入部件名称中互不相同的段（部件类型、变体段）组成前缀，如 `eagle.cast` 已存在则改用 `rec_mag_eagle.cast`；若仍被占用则数字递增 `rec_mag_eagle_2.cast`、`_3.cast`……自动命名永不覆盖；手动输入的文件名继续走覆盖确认对话框。

## 手臂武器拼接

默认关闭。在模型合并工作区工具栏勾选「手臂武器拼接」后，每个模型组出现拼接按钮：武器根骨骼以零位移挂接为手臂 `tag_weapon`（自动探测，可在目标骨骼下拉中改选）的子骨骼，武器骨骼层级与蒙皮权重完整保留，与手臂骨骼重名时自动加 `_wpn` 后缀，武器贴图路径改写为绝对路径。输出为全新 CAST（默认 `<代号>_viewhands.cast`，冲突时同样自动区分），写入临时文件并重新读取验证后原子发布，不修改输入文件。

## 功能对照与验收

| 上游功能 | 集成入口 / 验收要求 |
| --- | --- |
| 多个独立合并组，每组 2–15 个部件 | 模型合并页；多选导入、替换、移除、拖放、折叠 |
| 自动 / 手动根模型 | 每组根模型选项；使用原始合并核心 |
| 输出目录、文件名、覆盖确认 | 每组输出设置；准备完成后对最终路径加锁、确认后执行 |
| 单组 / 全部合并，队列与取消 | 最多两项同时运行；排队取消和协作取消；不强杀正在落盘的任务 |
| 实时阶段、进度与日志 | 后台 JSONL 事件；失败保留输入，可修正后重试 |
| 校验后写出 | 上游临时文件、回读校验、原子提交；不会边写边修改源文件 |
| 独立 CAST / 部件 / 结果预览 | 多个只读预览窗口；32 位索引，最多显示 250,000 个三角形 |
| 环绕、缩放、网格、复位、统计 | 预览窗口；拖动/滚轮和方向键、+/-、R、G、Esc |
| 弹匣填弹 | 选择武器和单 `tag_ammo` 骨骼弹药，分析弹匣与槽位 |
| 填弹范围控制 | 默认仅首个弹匣；其他槽位、备用弹匣显式选择；源弹匣布局复制 |
| 填弹写出保护 | 跳过已有弹药；新路径且不覆盖；保留上游骨骼、变换及资源预算限制 |
| 五种语言 | 模块提供中文、English、Français、Русский、Español |
| 设置与快捷键 | 模块设置不保存所选模型路径；Ctrl+N/O/S/Enter 在此页作用于合并工作区 |
| 主题、窗口、更新 | 统一使用 Alchemy Stars 的主题、窗口管理与更新入口，不运行另一产品的安装器 |
| 关于、源码、许可 | 保留源仓库链接及第三方许可；发布包带完整来源说明 |

预览采用软件逐像素深度缓冲，而不是上游 wgpu 渲染器；它保持正确遮挡与只读抽样语义，不承诺与上游相同的 GPU 吞吐量。抽样仅影响显示，不影响合并或填弹输出。

## 发布验证

发布前运行 vendored Rust 测试、进程协议测试、原生 AOT 界面/工作流检查和现有导出回归。具体结果记录于对应版本说明；此功能对照本身不代表检查已通过。
