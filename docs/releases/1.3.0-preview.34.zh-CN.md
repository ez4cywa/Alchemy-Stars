# Alchemy Stars 1.3.0-preview.34

基于 `v1.3.0-preview.33` / `codex/avalonia-aot`，重组左侧栏并把设置入口集成到窗口控件区，同时修复最小窗口下的文字裁切。

## 功能

- **左侧栏分组折叠**：分为「常用功能」（动画混合、模型部件、模型合并）与「其他功能」（双持动画、COD 武器库）两个可折叠分组；点击分组标题折叠或展开，状态保存在软件设置中，下次启动保持。
- **集成应用菜单按钮**：设置、关于从侧栏移出，收进窗口右上角最小化按钮左侧的单个应用菜单按钮；菜单内提供「设置」与「关于」。侧栏因此只保留功能分组，底部不再有固定偏好区。
- **语言选项移入设置页顶部**：设置页第一张卡片即「界面语言」，提供切换按钮与「跟随系统」；原「命名与语言」卡片更名为「命名规则」，只保留输出前缀与后缀。
- **最小窗口修复**：窗口控件列加宽后关闭按钮在 900×600 下完整显示；COD 武器库页改为按比例的弹性三列并保留最小宽度，右栏说明文字在可见区域内换行，不再超出窗口边缘。

## 兼容与运行

完整解压 `AlchemyStars-1.3.0-preview.34-win-x64.zip` 后运行 `AlchemyStars.Avalonia.exe`。保留 `Converters/alchemy-model-merger.exe` 及原生 DLL，无需安装 Rust 或 .NET。已有 Blender / Maya 导出配置继续使用。设置、关于、语言的新位置不改变快捷键（Ctrl+4 设置、Ctrl+5 关于）与工程数据格式。
