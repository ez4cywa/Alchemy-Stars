# Alchemy Stars 1.3.0-preview.17

本版新增快捷键和统一输出设置，并改进命名与标题栏。

- 快捷键：新建、打开、保存、另存为、导入、导出、预览与页面切换；按 `F1` 查看完整速查表。列表获得焦点时可用 `Delete` 删除条目、`Alt+↑/↓` 调整模型或动画层顺序。输入框保留文字编辑操作，排序后保持选中项。
- 默认输出名称使用第一条导入动画层的文件名（不含扩展名），后续导入不覆盖；已自定义的名称保留。
- “设置 → 实用功能 → 统一输出目录”可永久保存统一目录，普通动画和双持导出均优先使用它。不会改写项目内的目录，清除后恢复各条目设置；预览缓存不受影响。
- 修复输出路径等输入框右键菜单显示英文的问题，剪切、复制、粘贴随界面语言即时切换。
- 软件名称固定在窗口最上方正中，当前页面、项目和操作按钮位于下方。

下载 `AlchemyStars-1.3.0-preview.17-win-x64.zip`，完整解压后运行 `AlchemyStars.Avalonia.exe`。preview.16 用户也可通过程序内“检查更新”升级；更早版本需手动下载安装。

这是 Windows x64 自包含 Native AOT 预览版，无需另装 .NET。稳定版仍为 v1.1.9。
