# 1.3.0-rf.7：独立 RF 手臂工作区

RF 手臂适配从设置页移至左侧“工作区”，与动画混合、模型部件和双持合并并列。原有适配参数继续随工程保存，RF.6 的握持算法和穿模规则不变。

## 新布局

- 左栏：素材与参考、握持贴合、输出范围；单位/坐标轴和左右手高级微调按需展开。
- 右栏：实际生成的预览图、结果状态和输出文件。可直接打开 FBX、Blender 文件、预览图或报告。
- 底部：固定生成按钮和输入准备状态。未选参考或 RF 文件时说明缺少什么；生成期间禁用重复操作。
- 完成后直接显示结果，不再弹窗遮挡预览。失败保留配置并显示原因；更换工程清除旧结果。预览明确标注为上次生成的快照，不会随参数实时更新。

## 快捷键

Ctrl+6 打开 RF 工作区；Ctrl+E 在该页生成 RF 结果；Ctrl+I 导入源动画；F5 打开已生成的预览。原 Ctrl+1…5 不变。

沿用软件现有主题和紧凑导航，覆盖 900×600 及常规桌面尺寸、中英文和深浅色显示。

## 验证

Native AOT 自检、RF 实时控件测试、真实快捷键测试通过。已检查 900×600 与 1460×900 的中英文布局，以及原版、经典 Apple 的深浅色结果预览。短窗口限制输出文件区高度，保留可用的预览空间；参数和结果详情各自滚动。截图使用已有真实 RF 输出，不表示新增实时 3D 预览。
