# Alchemy Stars 1.3.0-preview.18

本版修正属性检查器与下拉选项显示，保留现有动画处理行为。

- 修复属性检查器滚动区域的输入框右边框显示不完整的问题。
- 切换语言或主题时，动画层类型、模型类型、双持模式和武器跟随选项保持原有选择，不再因刷新列表而改变工程设置。
- 武器跟随默认关闭，使用原始动画挂点；需要跟随手腕时由用户手动选择。
- 不包含已撤回的握持 IK 推导或肢段延展改动。

下载 `AlchemyStars-1.3.0-preview.18-win-x64.zip`，完整解压后运行 `AlchemyStars.Avalonia.exe`。preview.16 及更新版本可通过程序内“检查更新”升级。

这是 Windows x64 自包含 Native AOT 预览版，无需另装 .NET。稳定版仍为 v1.1.9。
