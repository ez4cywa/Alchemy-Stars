# Alchemy Stars 1.3.0-preview.35

本地开发版本，基于 preview.34。本轮采用 `the-pragmatic-programmer` 的单一知识来源与可重跑反馈规则，并用 `code-complete` 约束输入验证和失败路径实现。

## 改动

- 在 `fork/AlchemyStars/BuildVersion.props` 维护唯一版本值。Avalonia 和 Engine 共用版本；公开 `EngineVersion` 常量由构建生成，保留现有调用方式。发布脚本、启动检查和更新日志路径从共享元数据取得版本。
- 原生产物目录改为 `output/avalonia-aot-1.3.0-preview.35`。验证自行 restore，并从仓库根选择 SDK；Rust/restore 失败时保留上一份构建，所有退出路径恢复调用者目录和环境变量。新增 `-BuildOnly` 供编译检查使用。
- 单动画导出先解析最终输出目录，再与所有任务的源动画、左右姿势和动画层输入比较。解决输出目录为空或空白时漏检其他任务素材的问题。
- 绑定模型 FBX 先写同目录临时文件，转换成功后替换最终文件。转换器部分写入后失败时，旧 FBX 保持不变，失败的新文件与临时文件被清理。

## 重跑检查

```powershell
./scripts/test-build-configuration.ps1
./scripts/verify-avalonia-aot.ps1
```

工程脚本回归覆盖 4 种版本映射、8 种无效或歧义配置、8 种构建阶段与环境恢复场景。应用自测新增 32 个空目录/空白目录跨任务输入冲突场景、2 个真实生成 CAST 的安全导出，以及真实绑定模型导出分支的 FBX 故障与成功提交检查。

两处导出问题先由新增回归确认失败，再修复。FBX 故障回归使用受控转换器，验证文件保护，不代表已完成 Blender/Maya 格式与动画验证。完整构建工作流见 [工程指南](../engineering-workflow.zh-CN.md)。
