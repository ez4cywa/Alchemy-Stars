# Alchemy Stars 1.3.0-preview.25

发布日期：2026-09-11。Windows x64 Native AOT 预览版，稳定版仍为 v1.1.9。

## 新增与改进

- 选中动画后，点击“导出选中动画”或按 `Ctrl+Shift+E`，只导出该任务；`Ctrl+E` 仍导出全部。
- 保留选中任务的图层、IK、格式、命名和统一输出目录。未选中任务缺少素材不会阻止导出，但仍保护工程中所有源文件不被覆盖。
- 弹窗隔离后台操作，Tab / Shift+Tab 在弹窗内循环，Esc 关闭并恢复原焦点；长消息支持方向键及 Page Up / Page Down 滚动。
- 增加清晰的焦点框、弹窗消息与预览操作说明；“显示骨骼”作为真正的开关向辅助技术提供状态，并与 B 键同步。
- 包含 preview.24 的全部 FBX 轴向与单位修复。

## 验证与使用

单个导出及核心自测、中文/英文键盘交互、浅色/深色焦点显示、Windows UI Automation 和原有桌面快捷键验证通过。

完整解压 `AlchemyStars-1.3.0-preview.25-win-x64.zip` 后运行 `AlchemyStars.Avalonia.exe`，保留同目录插件、转换脚本及 DLL。
