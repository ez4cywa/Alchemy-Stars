# Alchemy Stars 1.3.0-preview.29

发布日期：2026-09-14。Windows x64 自包含 Native AOT 预览版，新增左侧「COD 武器库」栏目与 COD Wiki 图标对照。包含上一个预览版 preview.28 的动画工作流、预览控制与绑定模型导出改进。

- 左侧栏新增「COD 武器库」（`Ctrl+6`）。内置 CODWeaponDB v0.12.0 发布快照，可离线搜索武器名与控制台代号，支持代号前缀、游戏与类别筛选、蓝图条目和逐条来源链接。
- 新增「导入数据目录…」，选择任意 CODWeaponDB `dist` 目录即可替换内置快照；选择会被记住，「恢复内置快照」还原随包数据。损坏或缺少 `weapons.jsonl` 的目录会明确报错，不会静默丢弃数据。
- 新增从 Call of Duty Wiki 按需获取武器图标：先查页面首图，其次全文搜索，最后换名重试；图片缓存在本机，重复查询与重启后查询都不再联网。蓝图图片按其 `File:` 页面解析。Fandom 的 CDN 会返回 WebP，保存时按实际字节选择扩展名。
- 新增「对照窗口」：始终置顶、可与 CAST 预览并排的图标窗口，含 0.4–3 倍缩放，切换武器时同步更新，便于比对比例与轮廓。
- 新增 `cod-weapon-database` 图标，覆盖原版、经典 Apple、Windows XP、Windows 2000 四套内置图标与两份示例图标包（34 → 35 枚）。
- 新增 `--asset-pair-smoke <手臂.cast> <武器.cast> <动画.cast> <输出目录>`，用于检查任意一组手臂 + 武器在动画混合与挂点双持两条管线上的兼容性（真实素材不作为测试夹具提交）。已用 122 骨骼 rex 视图手臂与 112 骨骼 M4A1 武器实测：混合导出的完整场景保留 171931 顶点 / 234 骨骼 / 79 帧，武器根 `j_gun__weapon` 正确挂在 `tag_weapon` 下；挂点双持的绑定模型保留 258178 顶点 / 346 骨骼，`j_gun__left`/`j_gun__right` 分别挂在 `tag_weapon_left`/`tag_weapon_right` 下，骨架单根且骨骼名不重复，79 帧动画 CAST 不含网格。
- 修正 `DesktopSmoke` 只认识默认主题复选框部件名的问题：现在按各内置主题的实际部件名解析，Windows 2000 / XP / 经典 Apple 主题下不再误报。
- 修正语言切换时重建筛选下拉列表会把已选清空的问题：筛选改为绑定选中项并保持对象身份。

## 下载与运行

下载并完整解压 `AlchemyStars-1.3.0-preview.29-win-x64.zip`，运行 `AlchemyStars.Avalonia.exe`。无需安装 .NET；请保留程序同目录的原生 DLL。使用 FBX 导出时仍需配置对应的 Blender 或 Maya 后端。

「COD 武器库」的数据随包提供，离线可用；只有获取 Wiki 图标需要联网。用法见随包 `Docs/COD-WEAPON-DB.zh-CN.md`。
