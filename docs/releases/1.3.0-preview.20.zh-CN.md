# 1.3.0-preview.20

发布日期：2026-09-09。

- 修复右上角窗口按钮与工具栏的重叠；最小化、最大化和关闭按钮保留完整点击区域。
- 新增 Windows 2000 经典桌面主题：参考经典灰色面板、深蓝标题与选中态、凹凸方形控件，配套 34 个彩色像素图标；支持浅色、深色、跟随系统及设置持久化。
- 新增“共用前置动画批量叠加”：在动画层轨道栏点击批量图标，选用当前任务的基础动画和配置，为多选文件分别创建独立任务。选中动画层时替换该层，否则追加；原任务不变，重名输出自动加序号，再用“导出全部”导出。
- 保留原有冲刺批量生成入口，以及上一版的输出名同步、属性检查器和快捷键修复。

此版本仍为 Windows x64 Native AOT 预览版，不替代稳定版。
