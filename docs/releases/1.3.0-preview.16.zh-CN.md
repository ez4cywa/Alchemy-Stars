# Alchemy Stars 1.3.0-preview.16 更新日志

本版基于最新合并的 GitHub 修改继续开发，包含 `90f5e08` 的桌面窗口和内置外观整理。

## 实用功能

- 默认记住首次导入的手臂模型路径，启动或新建项目时自动加入，减少重复选择。打开已有项目不自动插入或替换模型。
- 可关闭自动复用、手动指定手臂模型或清除记录。关闭保留已记住的路径和当前模型；清除只移除记录，不删除模型文件。文件不存在时跳过复用并显示提示。
- 主题、明暗模式和自定义外观设置统一放到“实用功能”下方。

## GitHub 自动更新

- 自动更新默认关闭；开启后自动检查并下载同渠道的新版本。正式版只查正式版，预览版只查预览版，不自动跨渠道切换。
- 更新来源为 `ez4cywa/Alchemy-Stars` 的 GitHub Releases；下载后检查文件大小、SHA-256 和更新包结构。
- 下载完成不立即重启。需保存当前项目并确认重启后才安装；可以选择不更新，继续使用当前版本。
- **旧版本没有更新器，无法自动升级到本版。请首次手动下载安装 preview.16，之后才能使用程序内更新。**

## 下载与安装

下载 `AlchemyStars-1.3.0-preview.16-win-x64.zip`，完整解压后启动 `AlchemyStars.Avalonia.exe`。保留同目录 DLL、转换脚本、插件与样例目录。它是 Windows x64 自包含 Native AOT 预览版，无需单独安装 .NET 运行时。

首次手动升级前请保存当前工程并关闭旧程序。用户设置与外观副本保存在用户设置目录，不依赖下载 ZIP 中的原始模板；`.aprj` 工程格式保持兼容。

详细操作见随包 `Docs/USER-GUIDE.zh-CN.md`。本版继续使用 .NET 11 Preview 7 和 Avalonia 12.1.2，以预览版发布，稳定版仍为 WPF v1.1.9。
