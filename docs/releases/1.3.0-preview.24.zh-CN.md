# Alchemy Stars 1.3.0-preview.24

发布日期：2026-09-11。此版本为 Windows x64 Native AOT 预览版，稳定版仍为 v1.1.9。

## FBX 坐标系修复

- 合并模型 CAST 和 FBX 转换用的临时 CAST 保留源模型的 Y-up / Z-up 信息。
- Blender 路径统一转换模型与骨架对象，完整保留动画，再按源向上轴导出 FBX；修复米与厘米导致的 100 倍缩放差。
- Maya 路径显式设置场景向上轴、厘米单位和 FBX 导出轴，不再依赖工作站偏好。
- 缺少轴元数据时固定按新建 Maya 场景的 Y-up 处理。不同向上轴的模型部件无法直接混合，会明确报错，需先统一素材坐标系。
- 仅动画 CAST 的导出行为不变；本版本包含 preview.23 的全部时间线和资源工作流改动。

## 验证

在 Maya 2025 中，用 Y-up、Z-up 和无轴元数据三组测试素材分别验证 Blender 与 Maya 后端。比较 FBX 文件轴标签、三个动画帧的骨架世界矩阵和蒙皮顶点，六组均通过，最大误差小于 0.000004。Blender 回读验证、C# 元数据保留与混合轴拒绝测试、核心自测及 Native AOT 启动检查通过。

## 使用

下载并完整解压 `AlchemyStars-1.3.0-preview.24-win-x64.zip`，运行 `AlchemyStars.Avalonia.exe`。请保留同目录的转换脚本、插件及 DLL。

已生成的 FBX 不会自动更正，请使用新版本重新导出。Maya 会按当前场景轴转换导入的 FBX；与直接导入 CAST 比较时，应使用相同的场景向上轴。
