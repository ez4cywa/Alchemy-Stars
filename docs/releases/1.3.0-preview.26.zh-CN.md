# Alchemy Stars 1.3.0-preview.26

内部开发版本，未单独发布；改动已纳入 preview.27。以下记录本次开发时的行为，最终默认输出轴以 preview.27 的“保持原场景”为准。

- 输入模型不再要求相同向上轴，支持 X/Y/Z-up 混合；缺失或未知标记沿用 Y-up 默认解释。
- “设置 → 输出格式”增加输出向上轴选项，支持 Z-up（默认）与 Y-up，随工程与默认设置保存。
- 同步转换骨架、网格、法线、切线和动画，不修改原始素材。普通、选中、双持及配套模型导出共用此设置。
- 仅动画 CAST 也写入向上轴，预览相机自动适配文件轴。
- 增加两种输出轴的真实 CAST/SMD/SEAnim、混合轴双持、工程持久化和控件绑定回归；提供可选 FBX 导出回归入口。
