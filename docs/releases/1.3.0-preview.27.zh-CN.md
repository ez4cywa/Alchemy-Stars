# Alchemy Stars 1.3.0-preview.27

发布日期：2026-09-12。Windows x64 自包含 Native AOT 预览版，包含未单独发布的 preview.26 的混合输入轴与输出轴选择功能。

- 输出向上轴增加“保持原场景（不指定）”，作为未指定时的默认选择；仍可选 Z-up 或 Y-up，作用于整个输出场景。
- 保持模式沿用主模型的场景轴（优先手臂模型），不额外旋转原场景。混合输入仍对齐到同一个场景坐标系，源文件不变。
- 工程与默认设置保存此选择；旧工程已经指定的 Y/Z 选项保留。普通、选中、双持、配套模型及预览行为一致。
- 保留 X-up 场景时，FBX 使用 Blender 后端；Maya 支持 Y/Z-up。

## 下载与运行

下载并完整解压 `AlchemyStars-1.3.0-preview.27-win-x64.zip`，运行 `AlchemyStars.Avalonia.exe`。无需安装 .NET；使用 FBX 导出时仍需配置对应的 Blender 或 Maya 后端。
