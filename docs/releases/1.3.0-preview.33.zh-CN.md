# Alchemy Stars 1.3.0-preview.33

基于 `v1.3.0-preview.32` / `codex/avalonia-aot`，模型合并核心从 ModelMergerGUI 2.2.2 升级到 2.5.0（固定提交 `7cc474e707b1e3d971bfe2cb4855ec8a7df34e1d`），并新增本项目的命名冲突自动区分改进。包含 preview.32 的动画手部 IK 与 pose 匹配修正。

## 功能

- **手臂武器拼接**（可选，默认关闭）：在模型合并工作区工具栏勾选「手臂武器拼接」后，每个模型组出现拼接按钮。武器根骨骼以零位移挂接为手臂 `tag_weapon`（自动探测，可下拉改选）的子骨骼；武器骨骼层级与蒙皮权重完整保留，与手臂骨骼重名时自动加 `_wpn` 后缀；武器贴图路径改写为绝对路径。输出为全新 CAST，写入临时文件并重新读取验证后原子发布，不修改输入文件。
- **武器代号统一命名**（对齐上游 2.5.0）：合并输出默认 `<代号>.cast`（如 `att_sat_vm_ar_eagle_rec_LOD0` → `eagle.cast`），弹匣装填默认 `<代号>_filled.cast`，手臂拼接默认 `<代号>_viewhands.cast`；找不到部件类型段时回退完整文件名，名称始终可手动修改。
- **命名冲突自动区分**（本项目对上游的改进）：输出文件夹已存在相同代号的 CAST 时，自动提取本次输入部件名称中互不相同的段（部件类型、变体段）作为前缀，如 `eagle.cast` 已存在则生成 `rec_mag_eagle.cast`；若仍被占用则退回数字递增 `rec_mag_eagle_2.cast`、`_3.cast`……自动命名永不覆盖现有文件；手动输入的文件名沿用原有的覆盖确认对话框。
- 引擎同步上游 2.5.0 的材质槽改进：同名但贴图不同的材质在合并时保持独立，不再被错误合并；预览数据结构携带上游材质信息（本项目的软件深度预览仍使用中性灰几何显示）。

## 兼容与运行

完整解压 `AlchemyStars-1.3.0-preview.33-win-x64.zip` 后运行 `AlchemyStars.Avalonia.exe`。保留 `Converters/alchemy-model-merger.exe` 及原生 DLL，无需安装 Rust 或 .NET。已有 Blender / Maya 导出配置继续使用。协议向后兼容：`merge` / `inspect_ammunition` / `fill_ammunition` / `preview` 语义不变，新增 `inspect_arms` 与 `assemble` 两条命令。
