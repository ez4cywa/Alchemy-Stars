# Alchemy Stars 1.3.0-preview.30

发布日期：2026-09-15。Windows x64 自包含 Native AOT 预览版，为「COD 武器库」加入在线数据库更新。包含上一个预览版 preview.29 的 COD 武器库与 Wiki 图标对照。

- 「COD 武器库」新增在线更新：**检查更新**只读取上游 `main` 的 commit，不下载数据；**更新数据库**固定该 commit、下载 codeload 归档、重新解析 README 游戏目录与全部 `Games/*.md` 两列表格并重建数据集。数据卡片与标题栏都有入口。
- 更新遵循 CODWeaponDB 的 `github-only` 规则（同样的游戏标识、类别前缀表、来源 URL 与排序），因此刷新结果与上游应用同源；固定 commit、时间与来源写入 `refresh-manifest.json`，发布到 `%LOCALAPPDATA%\Alchemy Stars\CodWeaponDb\`。
- 更新采用临时目录 + 整体替换：任一阶段失败都会保留原数据集并给出原因，不会留下半成品。完成后自动切换到新数据，并报告记录数、游戏数与相对上一份数据的新增 / 移除 / 名称变更数量。
- 蓝图没有可对齐的上游表格，因此更新时把当前数据集的 `blueprints.json` 原样带入（无外部数据集时用随包 v0.12.0 副本），`游戏:武器名` 关联继续可用；武器图标仍按需从 COD Wiki 获取。
- 修正就绪状态未重新通知导致的按钮失效：目录加载完成前绑定的操作（更新数据库、获取图标）在加载完成后没有重新求值，会一直保持禁用。

## 下载与运行

下载并完整解压 `AlchemyStars-1.3.0-preview.30-win-x64.zip`，运行 `AlchemyStars.Avalonia.exe`。无需安装 .NET；请保留程序同目录的原生 DLL。使用 FBX 导出时仍需配置对应的 Blender 或 Maya 后端。

「COD 武器库」的数据随包提供，离线可用；获取 Wiki 图标与在线更新数据库需要联网。用法见随包 `Docs/COD-WEAPON-DB.zh-CN.md`。
