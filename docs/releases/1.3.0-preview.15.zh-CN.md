# Alchemy Stars 1.3.0-preview.15 更新日志

对比已发布的 `v1.3.0-preview.13`（提交 `b76e996`）。历史本地开发曾使用 preview.14，此次使用 preview.15，保留旧版本记录。

- 新增独立 Windows XP 主题，配套重绘 34 个矢量图标及控件外观；原版、经典 Apple 和拟物化主题继续保留。
- 完整重绘经典 Apple 的控件和 34 个功能图标，使用独立铂金浅色／石墨深色外观。
- 设置页新增一键明暗切换，选择自动保存，重新打开程序后继续使用。
- 支持导入自定义 JSON 主题，分别配置浅色、深色配色和控件圆角，并可选择内置基础风格。
- 支持导入 PNG 图标 ZIP 包，可只替换部分图标，其余继续使用内置图标；可恢复默认外观。
- 修复播放进度滑块裁切，起点、中点和终点的滑块均完整显示。

## 下载与使用

下载 `AlchemyStars-1.3.0-preview.15-win-x64.zip`，完整解压后启动 `AlchemyStars.Avalonia.exe`。这是 Windows x64 自包含 Native AOT 预览版，无需单独安装 .NET 运行时；请保留压缩包中的 DLL、转换脚本及插件目录。

自定义外观入口位于“设置”。包内 `Samples/Appearance/theme.json` 和 `Samples/Appearance/icons-template.zip` 可直接作为编辑模板；全部字段、图标命名和导入限制见 `Samples/Appearance/README.zh-CN.md`，操作说明见 `Docs/USER-GUIDE.zh-CN.md`。原有 `.aprj` 项目结构和动画导出工作流保持不变。

本版本基于 .NET 11 Preview 7 和 Avalonia 12.1.2，继续作为预览版发布；稳定版仍为 WPF v1.1.9。
