# 1.3.0-preview.22

本次新增 Ubuntu GTK/Yaru 风格控件模板，以及可直接导入的 Ubuntu 主题和完整图标包。

- 主题 JSON 支持 `baseStyle: "ubuntu-yaru"`，使用独立的 Avalonia GTK/Yaru 风格按钮、输入框、下拉框、复选框、开关、菜单、滑块与滚动条，不再借用经典 Apple 皮肤。
- 新增 13 个 `Gtk` 材质 token，支持单色或 2–5 色渐变；原有 JSON 和四套内置主题保持兼容。
- `Samples/Ubuntu-Yaru` 提供浅深色主题 JSON、34 枚透明 PNG 图标 ZIP 和中文导入说明。
- 覆盖橙色焦点、悬停、按下、禁用、复选框与开关状态，以及主题切换后的模板恢复。
- 保留 preview.21 的配件挂点修复，不修改动画叠加或 IK。

升级后，在「设置 → 外观」分别导入 `Samples/Ubuntu-Yaru/theme.json` 和 `Samples/Ubuntu-Yaru/icons.zip`。新版模板需要 preview.22 或更新版本。

这里的 GTK 控件是 Avalonia 实现的 GTK/Yaru 视觉与交互模板，不依赖 Linux GTK 运行库，也不执行外部 GTK CSS/XML。无需安装 GTK 或 .NET。此版本仍为 Windows x64 Native AOT 预览版。
