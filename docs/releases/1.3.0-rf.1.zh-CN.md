# Alchemy Stars 1.3.0-rf.1

本地 RF 实验版，基于 preview.27，位于独立分支 `EZ4/ravenfield-arms-adapter`，未合并到原分支，也未发布 GitHub Release。

- 新增“设置 → Ravenfield 手臂适配 · idle”，使用当前 COD 工程的参考帧、动画层、姿势和 IK 适配 RF 原版手臂。
- 根据样本尺寸默认按 COD cm → RF m 换算，也支持明确选择 ft 或 m；转换与普通导出流程隔离。
- 未标记坐标轴的武器/附件默认沿用 COD 手臂坐标轴，可手动覆盖，避免当前 Hawk 素材被侧转 90°；原始文件不改写。
- 保留 RF 蒙皮、指节长度和 COD 武器部件，提供左右手位置、旋转、肘部和手指微调，随工程保存。
- 输出可编辑 `.blend`、米制 Y-up FBX、预览图和检查报告。首版是两帧相同的静态 idle 校准姿势，不是全动画重定向。
- 设置目录与原版本分开；新增数值、蒙皮、FBX 往返、工程持久化和文件发布回滚验证。

解压 Windows x64 包后运行 `AlchemyStars.Avalonia.exe`；RF 功能需要本机 Blender，RF 素材从用户选择的文件读取，不随程序分发。详情见 [使用说明](../ravenfield-adapter.zh-CN.md)。

本机 Unity 批处理被未激活的许可证阻止，Unity 导入及游戏内效果尚未验证。
