# 1.3.0-preview.23

本次版本围绕 CAST 动画时间线、导出安全和资源库工作流进行修复与增强。发布包仍是 Windows x64 自包含 Native AOT 预览版，使用 .NET 11 Preview 7 与 Avalonia 12.1.2。

## 动画时间线与导出

- 所有 CAST 基础动画、手部姿势和动画层在进入合成管线时统一重采样到 30 FPS。程序读取 CAST 动画节点中的真实源帧率，按时间换算平移、旋转、缩放和动作轨道，而不是只修改帧率标签。
- 60 FPS、24 FPS 等非 30 FPS 源文件现在会保持正确的实际时长，并补齐 30 FPS 输出时间线中的中间姿态。输出帧数使用向上取整，避免末帧被截断。
- 无效、非有限或无法确定的 CAST 源帧率会在导出前明确拒绝。时间线元数据显示输出帧单位，轨道长度、播放和导出结果保持一致。
- 输出路径在整个批次范围内统一检查：不允许覆盖任何模型、动画、手部姿势或动画层输入，也不允许多个任务写入同一个输出文件。检测发生在实际写文件之前。

## CAST-only 输入规则

- 基础动画、动画层、左右手姿势、拖放路径、文件选择器、剪贴板粘贴和双持任务现在都严格要求 `.cast` 输入。
- `.seanim` 等其他格式仍可作为输出格式选择，但不会再被误放进 CAST 输入槽位后延迟到导出阶段才失败。
- 拖放、粘贴和文件选择器遇到不符合角色的文件时会保留当前工程数据，并显示明确的输入格式错误。

## 动画资源库与自动默认值

- 修复点击动画资源区删除按钮后闪退的问题。删除过程中会先清理双持任务引用、自动默认值、事件订阅和旧选中状态，再选择下一项；删除最后一项后资源库保持空选中状态。
- 自动生成的左/右手姿势和 IK 默认值现在根据同目录、同动画族、动作变体和唯一匹配结果进行分析；存在同分歧义时不会擅自填入错误文件。
- 自动默认值会在源动画或层发生变化后刷新，同时保留用户手动编辑过的姿势文件和 IK 字段。输出名称继续跟随首个动画层，并保留已有自定义名称。
- 检查器显示实际生效的统一输出目录；路径输入框、剪贴板菜单、拖放和异步文件选择在窗口状态变化时不会覆盖新选择。

## 验证与兼容性

- 新增真实 CAST 回归：验证 60 FPS 到 30 FPS 的总时长、平移中点和时间线帧数，确认碰撞拒绝不会改写输入文件，并确认非 CAST 输入被拒绝。
- 补充资源删除、动画族变体匹配、剪贴板/文件选择器竞态、界面绑定、主题切换、检查器焦点和 Native AOT 启动验证。
- 保留 preview.22 的 Ubuntu GTK/Yaru 风格控件模板、主题导入、34 枚图标包以及之前的配件挂点修复。

升级方式：完整解压发布 ZIP 后运行 `AlchemyStars.Avalonia.exe`。软件不需要另装 .NET；FBX 转换仍需要外部 Autodesk Maya 环境。当前分支仍是预览测试线，稳定版继续是 `main` 上的 WPF v1.1.9。
