# Alchemy Stars 1.3.0-preview.36

2026-10-15 预览版本，基于 preview.35。采用用户选定的 Linear 工作台方向，并补齐工程加载与设置恢复的失败路径。发布到 `codex/avalonia-aot` 开发分支及 GitHub 预览渠道，不合并 `main`、不替换稳定版。

## Linear 工作台

- “原版 · 简洁”更新为“Linear · 工作台”，使用中性浅深工作面、紧凑排版、克制选中态与可着色线性图标；保持资源库、合成预览、动画层、属性检查器与现有导航流程。
- 保留经典 Apple、Windows XP、Windows 2000、Ubuntu/Yaru 自定义基础风格及独立图标包。原版内部键仍为 `apple`，`modern-desktop` 和 `neumorphic` 继续映射到它；version 1 自定义主题无需迁移。
- 自定义 `radii.Button` 覆盖导航、图标、工具栏及面板命令按钮，图标数量从程序支持列表派生，避免状态文字与实际导入能力不一致。
- 修正 Avalonia 样式优先级：将无条件按钮规则与条件类规则分开，避免旧的选中态覆盖导入圆角；`radii.Card` 继续控制卡片，不改作面板半径。
- COD 武器库窄窗口标题栏改为两个 44×44 图标命令，保留本地化提示和辅助功能名称，避免长按钮文字遮挡标题。
- 区分强调文字与按钮填充色，校验浅深色正文、次要文字、强调文字、输入边界、焦点及开关的对比度。
- 设计参考来自 [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md/tree/3b605329240ce735b510037cca322f1831fdd7f8)，固定提交 `3b605329240ce735b510037cca322f1831fdd7f8`。该仓库作为全局设计参考安装，不是可执行插件或技能；本项目的取舍见 [设计约定](../../DESIGN.md)。

## 存储保护

- 工程文件中的 `Parts`、`Animations`、`DualAnimations` 和动画 `Layers` 集合出现 `null` 条目时，在替换工作区前报告无效数据；旧工程的 `null` 集合仍按空集合读取。
- 加载失败时保留当前工作区、选中项和原保存路径，后续保存继续使用原工程。
- 设置文件在首次读取时被独占锁定，解除后重新读取原持久值，并保留锁定期间的内存修改；后续保存不以默认值覆盖手臂路径、目录和格式等无关偏好。
- 设置写入遇到 I/O 失败时仍允许界面继续使用内存修改，后续可写时保存；沿用已有同目录临时文件与替换流程。

本轮采用 `a-philosophy-of-software-design` 的信息隐藏规则，将设置恢复和无效工程处理保留在存储模块内部，调用方继续使用已有接口。

## 检查范围

回归新增工程空条目、失败加载隔离、设置读锁恢复、锁定期间修改和写入失败场景。外观回归扩展到 COD 武器库、模型合并，以及五种基础风格在浅深模式下的自定义按钮圆角。

开发检查命令：

```powershell
./scripts/test-build-configuration.ps1
./scripts/verify-avalonia-aot.ps1
```

只检查自定义外观时，可使用更小的反馈循环：

```powershell
AlchemyStars.Avalonia.exe --custom-appearance-smoke --culture zh-CN --window-size 900x600 --render-smoke "output/custom-appearance/result.png"
```

请用独立的 `ALCHEMY_STARS_SETTINGS_PATH` 运行开发回归，避免测试改变日常设置。
