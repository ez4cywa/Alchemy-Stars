# Alchemy Stars 1.3.0-preview.13 更新日志

对比基准：`ez4cywa/Alchemy-Stars` 的 `codex/avalonia-aot`，提交 `c817e47`（preview.12）。

- 新增双持动画页面：把左右单持动画合成为一套骨架和一个双持动画，支持预览、单项导出和批量导出。
- 支持两种武器模型处理模式：复制一把武器并挂到左右手，或拆分一个模型中已有的左右武器。
- 新增“导出武器模型”开关，可同时输出包含手臂、左右武器和统一骨架的独立模型文件。
- 新增“武器跟随”：武器可以跟随左手或右手，保留初始握持偏移，减少叠加动画时手与武器分离的问题。
- 导出报错更具体：标明左右任务、动画文件、叠加层及帧率差异，方便定位问题。
- 提供原版、经典 Apple 和拟物化三种界面风格，支持浅色、深色及跟随系统；旧主题和已有偏好继续保留。
- 经典 Apple 使用铂金与石墨配色，交互色与图标不使用蓝色；重绘 34 个单线矢量图标，统一安全边距，避免导航和工具栏图标遮挡或裁切。
- 统一单行控件文字垂直居中，多行编辑框保留顶部对齐；验证两种窗口尺寸下全部主题和五个页面。
- 双持工作区支持拖动调整列表和属性面板宽度；“武器跟随”默认折叠，并使用独立图标；模型处理模式也增加独立图标。
- 新增 Blender FBX 转换支持，优先使用 Blender 4.3，同时保留 Maya 转换方式。
- 修复“关于”页面两个项目链接的启动与失败反馈，打不开网页时可复制网址。

版本统一为 `1.3.0-preview.13`，包括程序显示、导出引擎和打包脚本。这次将本地 UI 分支的最终修改一并合入 AOT 分支；本地曾使用 preview.14 编号，此次按目标仓库的 preview.12 → preview.13 顺序编号，功能没有回退。

使用说明：[双持动画](../dual-wield.zh-CN.md)、[同一模型包含左右武器](../combined-dual-weapons.zh-CN.md)、[武器跟随](../weapon-follow.zh-CN.md)。

注意：武器跟随不会为源动画补出不存在的手臂动作；源动画和叠加层仍需满足任务的帧率要求。
