# Alchemy Stars 1.3.0-preview.32

基于 `v1.3.0-preview.31` / `codex/avalonia-aot`，本次集中更新动画混合、手部 IK 与 pose 自动匹配。

## 功能更新

- **idle 手部漂移修正**：重采样前归一化旋转关键帧，各动画层采样后再次归一化骨骼旋转。两段式 IK 保留微小角度修正，并在更新世界旋转时保留骨骼局部位移，避免微小误差造成握持滑动。
- **换弹时跟随 hand mover**：动画同时包含对应 mover 关键帧、手部 mover 标记，且骨架中存在有效目标时，使用 `tag_ik_target_left_mover` / `tag_ik_target_right_mover`。依据进入、保持和退出标记，在普通握持目标与 mover 目标之间混合后求解，沿用原有左右手 IK 开关和动画层起始帧偏移。缺少所需数据时保留原有处理；已烘焙的 mover 标记不再写入输出。
- **跨动画名称匹配 pose**：自动选择基础动画后，优先查找该基础动画的左右手 pose；缺失时才尝试导入动画的匹配结果。
- **鼓匣／扩容弹匣 pose 回退**：优先匹配完整武器家族，其次去除末尾 `drum` / `xmag` 变体标识查找基础家族，最后尝试通用 pose。候选存在歧义时保留空值供手动选择。

自动匹配改动作用于重新分析和添加任务，不会批量改写已有 `.aprj` 工程中的空白 pose。已有任务可手动补齐或重新分析生成。

## 运行与兼容

完整解压 `AlchemyStars-1.3.0-preview.32-win-x64.zip` 后运行 `AlchemyStars.Avalonia.exe`。保留原生 DLL、`Converters` 及随包资源，无需安装 .NET 或 Rust。

沿用 .NET 11 Preview 7、Avalonia 12.1.2 与现有 Native AOT 发布方式，保留 preview.31 的模型合并、弹匣填弹、COD 武器库及 Blender / Maya 导出支持。本版不引入新的 IK 配置项或工程格式。

## 编译与验证范围

本次仅进行 Native AOT 编译、源码差异和压缩包内容检查，未运行功能、动画导出或页面测试；实际握持和换弹效果仍需用目标素材确认。此前版本的测试记录不代表本版已通过对应测试。

发布脚本的 `-SkipVerification` 现同时跳过外观示例的运行与渲染检查。Native AOT 编译保留 Avalonia Win32 DComposition 的两条非 blittable 参数诊断。
