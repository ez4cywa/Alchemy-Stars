# 1.3.0-preview.19

发布日期：2026-09-09。基于 ez4cywa 的 `codex/avalonia-aot` 最新 preview.18 合并 UI 修复。

- 选中动画层后自动展开对应属性并带入可视区，解决保留旧滚动位置导致字段藏在上方的问题。
- 资源库长名称改为中间省略，保留动作后缀，便于区分 reload、melee 等同名前缀动作。
- 关于页版本徽标绑定实际版本，避免与窗口、状态栏不一致。
- 图层、手部姿势、武器跟随和 IK 折叠标题及按钮使用可随语言更新的无障碍名称。
- 保留 preview.18 的属性边框和选择状态修复，以及此前的快捷键、更新检查、统一输出目录功能。

自定义主题包、预览图和用户测试项目不包含在源码提交中。此版本仍为预览版。
