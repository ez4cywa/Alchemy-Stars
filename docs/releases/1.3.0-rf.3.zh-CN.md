# 1.3.0-rf.3：主掌面对齐与独立质量判定

这是掌面适配的第一阶段，不是全手握持已经解决。

- 新增默认开启、可关闭的“自动对齐主掌面”，跟踪绑定网格上的固定对应点，不再只检查手腕重合。
- 比较统一模型空间下的实际蒙皮位置，以有限平移/旋转改善主掌面贴合，再求解手臂；保留 RF 网格、骨长、权重及源手指方向。
- 在同一历史姿态下比较修正前后，只保留实测误差更小的结果。逐帧报告误差及修正步长。
- 将文件生成与掌面质量分开：超过 5 mm 的片段明确标为“需检查”，输出仍可编辑。
- 保留完整动画、单文件动画库与 Unity 切片工具。

## 实测范围

Hawk idle 左手最大对应点偏差 13.25 → 4.85 mm，右手 10.71 → 3.91 mm；实际蒙皮检查通过 5 mm 目标。

整段测试并未全部达标：Sprint 1 帧略超 5 mm，Reload 27 帧超标、最大约 6.45 mm，Inspect 248 帧超标、最大约 11.00 mm。报告保留具体帧。这些数值只覆盖四个主掌面采样点，不代表虎口、手指、全表面间隙或无穿模。

Unity Editor/游戏内验证仍受本机未激活许可证限制。此次没有改变 Unity 工程或源模型。
