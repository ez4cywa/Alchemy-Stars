# 1.3.0-preview.21

本次修复配件自动挂接时的位置和旋转错位，保留 preview.20 的全部功能。

## 配件挂点修复

- 配件根骨骼与同名武器挂点的绑定位置、旋转和缩放一致时，继续复用已有骨骼。
- 不一致时，将配件根挂到该挂点下面，使原点制作的配件正确继承挂点变换。
- 手动指定父骨骼仍优先；缺失或重名挂点仍报错，不进行猜测。
- 不改变动画叠加、手部 IK 或双持的显式挂接逻辑。

## 验证

新增回归覆盖绑定变换复用（含等价四元数）、位置/旋转/缩放差异、手动父骨骼、缺失与重名挂点，以及共享引擎导出后的配件顶点位置。

这是自包含 Windows x64 Native AOT 预览版，无需单独安装 .NET。正式稳定版仍为 v1.1.9。
