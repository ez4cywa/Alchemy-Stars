# Alchemy Stars 1.3.0-preview.28

发布日期：2026-09-13。Windows x64 自包含 Native AOT 预览版。

- 动画混合工作区会检查类型为“武器”的 CAST 模型；存在精确骨骼 `tag_ik_loc_le_foregrip` 时，自动填入动画任务的左手 IK 目标。未找到时保持字段为空，继续使用工作区默认目标。
- 输出帧率改为每个动画任务可编辑，默认值为 30 FPS，并允许填写大于 0 的自定义帧率。
- 基础动画、左右手姿势和动画层会按目标帧率重采样，保持原动画时长和对应时间点姿势；时间轴帧数也会随输出帧率刷新。
- 项目加载时会把无效帧率恢复为 30 FPS，导出前会拒绝非有限值及小于等于 0 的帧率。
- 修正 900 × 600 窗口及高 DPI 环境下顶部产品标题的居中基准，并增强 Native AOT 无障碍检查的冷启动等待。
- 修正“保持原场景”仍会按错误 CAST 轴标记转换动画的问题：默认模式现在保留模型和动画的原始坐标；只有明确选择 Y-up/Z-up 时才按标记转换。第一人称预览会完整容纳场景。
- 修正“保持原场景”合成预览错误采用手模 Y-up 标记而显示成俯视图的问题；预览相机现在优先采用基础动画的轴标记。预览区右上角新增 Blender 风格 XYZ 相机旋钮，可拖动环绕、点击正负轴端点切换视图，并支持键盘 X/Y/Z（Shift 为负轴）。
- 动画与预览改为独立产物：正式动画 CAST 默认只包含动画数据，不再需要“仅输出合并动画 CAST”开关；合成预览始终生成含手臂和武器网格的私有完整 CAST，不会因精简动画而丢失模型。
- “模型部件”资源库新增“导出绑定模型”。它复用动画混合的骨架挂接、网格变换和蒙皮权重重映射，按 `武器源文件名_model` 命名；CAST、FBX、SMD、SEAnim 动画格式分别对应 CAST、FBX、SMD、SEModel 模型。Blender FBX 转换现已支持不含动画的模型 CAST。

## 下载与运行

下载并完整解压 `AlchemyStars-1.3.0-preview.28-win-x64.zip`，运行 `AlchemyStars.Avalonia.exe`。无需安装 .NET；请保留程序同目录的原生 DLL。使用 FBX 导出时仍需配置对应的 Blender 或 Maya 后端。

- 托管构建通过，0 warnings、0 errors。
- Native AOT 发布版内置自测通过，覆盖前握把 IK 自动目标、30/60 FPS 重采样、时间轴、工程持久化、输出冲突和 CAST-only 输入校验。
