# 1.3.0-rf.2：完整动画与单文件动画库

独立本地实验分支 `EZ4/ravenfield-arms-adapter`，保留 rf.1 静态姿势模式及普通导出流程。

- 新增“完整动画”：把选中参考动画的所有已求值帧适配到 RF 手臂。
- 新增“工程全部动画（同一文件）”：同一 FBX 内按 `Scene` 的命名帧区间组织所有动画，与 RFTools 示例武器的组织方式一致；`.blend` 保留每段独立 Action。
- 片段分别计算动画层、手部姿势及 IK，统一 30 FPS；参考帧只用于视角校准和预览。
- 改善伸直手臂附近的肘部连续性，保留源指骨的完整旋转，避免检视动作中的额外手指翻转。
- 附带 Unity 手动切片菜单脚本，根据报告设置片段名称及区间。

真实 Hawk 的 Idle、Sprint、Reload、Inspect 共 451 个片段帧，另有 30 个间隔帧。已检查全部 481 帧的 FBX 回读、骨架层级与蒙皮，以及关键动作画面。FBX 最大顶点往返误差约 0.00000194 m。

尚未完成 Unity Editor/游戏内验收：本机 Editor 许可证未激活。切片脚本已通过 Unity 2020 程序集编译。事件、音效、循环设置及武器预制体仍需配置；不自动消除手型穿模，也不补齐缺失贴图。

用法见 [RF 使用说明](../ravenfield-adapter.zh-CN.md)。
