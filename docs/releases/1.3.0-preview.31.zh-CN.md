# Alchemy Stars 1.3.0-preview.31

基于 `v1.3.0-preview.30` / `codex/avalonia-aot`，左侧新增「模型合并」（Ctrl+7）。来源为 ModelMergerGUI 2.2.2，固定提交 `ac0bfeb577651c34b3de4fdbafa4b1f615e5f84f`。

## 功能

- 多组合并，每组 2–15 个 CAST 部件；多选导入、替换、移除、拖放、折叠，自动或手动指定根模型。
- 单组 / 全部运行，最多两项并行；支持排队和运行中取消、阶段进度与日志。解析最终输出路径后加锁，确认覆盖才执行；窗口关闭等待任务协作退出。
- 弹匣填弹：分析槽位与已有弹药，默认仅第一个弹匣；其他槽位、备用弹匣显式选择，按选定源弹匣复制布局；输出必须是新文件。
- 独立预览部件、结果或任意 CAST，多个窗口，旋转 / 缩放 / 网格 / 复位 / 统计，支持 32 位索引和最多 250,000 个显示三角形。只读抽样不改变输出。
- 模块五种语言与窗口位置保存；主题和软件更新统一沿用 Alchemy Stars，不安装另一款 GUI。

预览采用逐像素**软件深度缓冲**，不是上游 wgpu 渲染器。遮挡正确性有测试覆盖，GPU 性能不作等价承诺。

## 兼容与运行

完整解压 `AlchemyStars-1.3.0-preview.31-win-x64.zip` 后运行 `AlchemyStars.Avalonia.exe`。保留 `Converters/alchemy-model-merger.exe` 及原生 DLL，无需安装 Rust 或 .NET。已有 Blender / Maya 导出配置继续使用。

本版不混入 RF 实验分支，不修改 Unity 工程或已有骨骼/动画导出约定。模块写出 CAST；Unity 所需格式通过原有导出流程处理。

## 验证记录

- Rust：31 项上游测试、7 项真实进程协议测试通过。新增覆盖准备与执行分离、取消/EOF 清理、已有及中途新出现文件的覆盖保护、填弹复制和不覆盖。
- 真实 Hawk：5 部件合并得到 74 根骨骼、18 个网格、79,288 个顶点；真实弹药填充加入 20 份网格，结果可预览，源文件 SHA-256 不变。
- C# 服务、工作区与 Native AOT 检查通过：自动/手动根、覆盖允许/拒绝、输出锁、双槽队列、排队与运行取消、导航、编辑、五语言状态保持、设置不保存所选模型路径。填弹验证默认范围、3 处插入、额外槽位单独填充、拒绝覆盖及关闭取消；关闭软件期间阻止新任务并等待清理。
- 预览：交叉三角深度遮挡、32 位索引、250,000 上限、相机/网格/取消测试通过。修复无图片源时尺寸为零导致的首帧空白，真实 Hawk 填弹模型窗口显示 93,410 个三角面，五语言截图通过目检。
- 原有 Native AOT 回归通过：self-test、更新器、无障碍、快捷键、文本菜单、属性栏、窗口控件、双持批处理、COD 武器库、页面与提示渲染、900×600 / 1366×768 主题与导航。
- 旧 Hawk 示例项目因引用的合并模型路径缺失而跳过；改用本机真实手臂、此次填弹输出和 Hawk 开火动画检查兼容性。修正旧测试直接比较不同 FPS 帧数的误判，61 帧 @ 60 FPS 对应 31 帧 @ 30 FPS，动画算法未改动。
- Blender 4.0.2 将填弹结果导出 FBX 后重新导入：74 根骨骼、38 个网格、86,528 个顶点，全部网格仍有骨骼绑定和有效权重。素材未包含贴图，贴图路径警告不作为贴图验收通过；未修改或启动用户的 Unity 工程。

构建仍使用 preview.30 同一 .NET / Avalonia 版本。Native AOT 编译器保留 Avalonia Win32 DComposition 的两条非 blittable 参数诊断；本机窗口、主题和渲染回归通过，本版未改写该上游实现。

完整功能对照见 [模型合并工作区](../model-merger.zh-CN.md)。
