# Ubuntu · Yaru Studio

Alchemy Stars 本地主题包，适用于支持自定义外观的 preview.22 及之后版本。配套软件已加入独立的 Ubuntu GTK/Yaru 风格控件模板。

## 导入

1. 打开软件「设置 → 外观 → 导入主题 JSON」，选择本目录的 `theme.json`。
2. 点击「导入图标 ZIP」，选择本目录的 `icons.zip`。
3. 选择浅色、深色或跟随系统。主题已包含两套配色；图标在两种模式下共用。

不要把整个主题文件夹作为图标包导入；只有 `icons.zip` 是图标导入文件。`icons/` 是单独的 PNG，`Source/` 是可编辑 SVG 源文件，均无需额外导入。

## 设计

暖灰色工作面、深炭灰命令栏、橙色主操作与焦点、少量茄紫动画轨道。按钮为 5 DIP 圆角，轻微高光和清晰的悬停/按下状态。34 枚图标统一为 Suru 风格圆角彩色底形与白色功能符号，64×64 透明 PNG，附矢量源文件。每个图标的图形按软件功能重新绘制，不是 Ubuntu 官方图标资产。

外观参考：[Ubuntu Yaru 官方项目](https://github.com/ubuntu/yaru)。这是风格适配，不是官方 Ubuntu 主题。软件支持的是配色、部分控件材质、圆角和 PNG 图标，不能导入 GTK 模板，也不能通过主题改字体、布局、标题按钮形状或应用任务栏标志。本包使用 `baseStyle: ubuntu-yaru` 启用独立的 Avalonia GTK/Yaru 风格按钮、输入框、下拉框、复选框、开关、滑块、滚动条与菜单模板。`Gtk` 材质 token 控制这些模板的配色。这不是 GTK 运行库，不执行 GTK CSS/XML；旧版软件不能读取这个基础风格，请先使用 preview.22 或更新版本。

浅色强调色适当加深，以保证小字号橙色文字和白色按钮文字可读。图标自带底色，避免单色图标在浅色或深色背景消失。

## 恢复

「移除自定义主题」恢复内置主题；「恢复内置图标」移除图标覆盖。两项独立操作，不影响工程。本主题只提供文件，没有更改你当前的应用设置，也没有覆盖程序文件。
