# Alchemy Stars Avalonia 预览版快速指南

本指南适用于 `1.3.0-preview.16`。在 .NET 11 GA 前，WPF v1.1.9 仍是受支持的稳定版。

侧栏用于切换“动画混合、模型部件、双持合并、设置、关于”，正常宽度下显示图标和名称，窄窗口下折叠为图标栏。左侧为资源库，中央显示真实 CAST，底部横跨资源库和预览区显示合成图层，右侧为可折叠属性。分隔条支持拖动，也可获得焦点后用方向键调整。图标提供双语工具提示和 UI Automation 名称，标题栏显示当前页面，窗口按钮位于右上角。

1. 打开“模型部件”，先添加手臂，再添加武器与附件。软件会根据每个 CAST 的骨架结构识别类型；属性检查器显示置信度和依据，为武器推荐 `tag_weapon`，类型与父骨骼仍可手动覆盖。低置信度或无法读取的文件会明确提示确认；打开已有 `.aprj` 时不会自动重分类。
2. 打开“动画混合”并添加基础动画。所有路径都可编辑，也能直接粘贴 Windows“复制文件地址”得到的带引号路径。
3. 按需添加左/右手姿势文件，只启用动画实际需要的 IK 链。
4. 按顺序添加动画层。在“动画层”区域拖入或右键导入的文件始终作为动画层处理，不会被当成新的基础动画。
5. 填写输出名称并明确选择输出目录。新动画会有意将此字段留空。
6. 在“设置”中选择 CAST、FBX、SMD 或 SEAnim。“仅动画 CAST”和“仅烘焙相关骨骼”是可选项；若优先考虑最大兼容性，请保留完整烘焙。
7. 点击“导出全部”或按 `Ctrl+E`。进度与结果始终显示在软件界面中央。

软件会按用途记忆每个文件浏览器的最近目录，并可跟随 Windows 显示语言或固定为中文/英文。项目文件继续兼容原有 `.aprj` 结构。

标准 Hawk 流程请打开 `fork/AlchemyStars/Example/Hawk/HawkSprint.aprj`。托管运行与 Native AOT 导出验证都以它作为唯一配置来源。

## 实用功能：记住手臂模型

“设置 → 实用功能”中的“自动复用首次导入的手臂模型”默认开启。首次导入手臂后，程序记住文件路径，之后启动或新建项目时自动加入该手臂；打开已有 `.aprj` 不插入、不替换已有模型。保存的是路径，不会复制手臂素材。

关闭开关只停止自动复用，保留记录和当前模型。“选择手臂模型…”可手动指定其他文件；“清除记录”只忘记路径，不删除原始文件或当前项目中的模型，开启自动复用时下次首次导入可重新记住。已记住的文件不存在时跳过复用，并显示缺失提示。

## GitHub 更新

自动更新默认关闭。开启后，程序从 `ez4cywa/Alchemy-Stars` 的 GitHub Releases 检查并下载更新，只选择比当前版本更新的同渠道版本：预览版保持预览渠道，正式版保持正式渠道。下载包会检查大小、SHA-256 和结构。

下载完成后仍需保存当前项目并确认重启，程序才安装更新。可以选择不更新，继续当前工作；不会仅因下载完成便强制重启。旧版没有此更新器，必须先手动下载并安装 preview.16，之后才能使用程序内更新。

## 自定义主题和图标

外观相关设置位于“设置”的“实用功能”下方。

“设置”中的外观区域提供原版、经典 Apple 和 Windows XP 风格。原版采用现代桌面外观，保留原版图标。独立现代桌面主题已移除，旧偏好自动转为原版。可选择浅色、深色或跟随系统，也可点击明暗切换按钮直接切换；外观选择自动保存，不修改工程文件。

preview.15 完整重绘经典 Apple 的控件与 34 个功能图标，采用独立铂金浅色／石墨深色外观；Windows XP 也提供独立控件及 34 个配套图标。

- 导入主题：以压缩包内 `Samples/Appearance/theme.json` 为模板，修改后在设置页选择“导入主题”。`version` 使用 `1`，`name` 为主题名称，`baseStyle` 指定内置基础风格；`light` 和 `dark` 分别为配色 token 对象，`radii` 为控件圆角配置。
- 导入图标：以 `Samples/Appearance/icons-template.zip` 为模板，用同名 PNG 替换要修改的图标，重新打包为 ZIP，再选择“导入图标”。支持只提供部分图标，其余继续使用主题的内置图标。
- 恢复默认：分别使用“移除自定义主题”和“恢复内置图标”。主题与图标独立管理，不删除原始导入文件，也不影响动画工程。

切换内置主题会停用自定义配色和圆角，但自定义图标继续生效。导入内容复制到设置目录，重启后保留。完整格式、全部 token、34 个图标文件名及限制见随包 `Samples/Appearance/README.zh-CN.md`。

## CAST 合成预览

点击合成工作区标题栏的“合成预览”，使用现有导出引擎将所选动画合成为唯一的临时 CAST。此操作不需要填写、不修改正式输出目录；读取独立场景后清理本次缓存。“打开 CAST 预览”可读取已有的合并文件。导出 CAST 成功后会自动显示所选条目的结果。

- 拖动视口或按方向键旋转，滚轮或 +/− 缩放。
- 点击摄像机按钮或按 `1` 进入固定第一人称视角：摄像机采用 Maya 新建摄像机的 `T(0,0,0)`，旋转为 `R(90°,0°,-90°)`，水平 FOV 为 90°。仅用于预览的安全取景会保持武器完整显示，不会修改 CAST 场景或导出结果。再次按 `1` 或使用任一“适应”命令即可返回环绕视角。
- 播放按钮、空格、帧滑块及上一帧/下一帧按钮用于查看动画。
- F 聚焦主体；右键“适应主体”或 Shift+F 可查看全部几何体，包括移到远处的备用部件。
- 骨架按钮切换骨骼叠加。“仅动画 CAST”只含曲线、不内嵌骨架；请先在当前工程加载匹配的模型部件。视口会提示使用了工程骨架；仅骨骼名称匹配不能保证绑定姿势一致。
- 当前为不含贴图/材质的灰模预览。修改设置不会自动重算快照，请再次点击“合成预览”。
- 轨道条会在后台读取源文件元数据：宽度表示真实 CAST 帧数，横向位置包含所设帧偏移，标题栏显示共同帧范围。条内文字同时标出帧数；无法读取的源文件仍会显示，并明确标为“帧数未知”。
- 动画采样、蒙皮、投影和光照在后台运行，同一时刻最多准备一帧，投影分辨率上限为 960×640；交互式视口通过 Avalonia 的 GPU 加速 Skia 自定义绘制提交三角形，并保留确定性的 CPU 渲染器用于无界面验证。实际播放性能取决于场景复杂度，最终使用效果仍应在 Maya 中验证。

键盘快捷键：

| 操作 | 快捷键 |
| --- | --- |
| 打开项目 | `Ctrl+O` |
| 保存项目 | `Ctrl+S` |
| 项目另存为 | `Ctrl+Shift+S` |
| 导出全部 | `Ctrl+E` |
| 切换 CAST 第一人称预览 | `1` |
| 关闭结果/错误对话框 | `Esc` |

合并 CAST 的有权重网格默认使用 DQS（`quaternion`）蒙皮。随附 Maya 导入器会遵从 CAST 中明确指定的方法；旧文件未指定时也默认使用 DQS。

迁移架构、包体积与验证证据见 [Avalonia + Native AOT 迁移报告](avalonia-aot-migration.md)。
